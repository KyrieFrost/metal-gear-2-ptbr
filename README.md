# Metal Gear 2: Solid Snake - Tradução PT-BR

Patch de tradução para português brasileiro de **Metal Gear 2: Solid Snake**, disponível em duas edições:

- PlayStation 2: `Metal Gear Solid 3: Subsistence - Disc 2`
- PC: `METAL GEAR & METAL GEAR 2 - Master Collection Version`

Depois de instalar qualquer uma das versões, configure o idioma do jogo como **Espanhol**. A tradução substitui essa localização.

## PlayStation 2

### Compatibilidade

O patch foi produzido para a edição americana:

- Jogo: `Metal Gear Solid 3: Subsistence - Disc 2 of 3`
- Serial: `SLUS-21243`
- SHA-256 da ISO original: `212FE7AD9A7420836562E565B14AB0FA174AE654EFFEE9E401018B87F63FA142`

### Instalação

1. Extraia uma ISO do seu próprio disco original.
2. Abra um aplicador compatível com patches XDelta3.
3. Selecione sua ISO original como arquivo de origem.
4. Selecione `PS2/Metal_Gear_2_PTBR_PS2_SLUS-21243_v1.0.xdelta` como patch.
5. Escolha um nome diferente para a ISO de saída e aplique o patch.
6. Inicie a ISO criada e selecione **Espanhol** no menu de idioma.

O patch recusará uma ISO de outra região, revisão ou com modificações anteriores.

## Master Collection no PC

### Instalação

1. Feche o jogo antes de continuar.
2. Execute `Master-Collection/Instalar_Traducao_MG2_PTBR_v1.0.1.exe`.
3. Selecione a pasta raiz que contém `METAL GEAR.exe`.
4. Pressione **Instalar**.
5. Abra o jogo e configure o idioma como **Espanhol**.

O instalador verifica os arquivos originais antes de modificá-los e cria um backup local. Caso a verificação falhe, restaure os arquivos pela Steam e tente novamente.

### Desinstalação

Depois da instalação, o arquivo `Desinstalar Tradução.exe` será criado na pasta raiz do jogo. Execute-o para restaurar os arquivos originais e remover a tradução.

## Aviso legal

Este projeto distribui somente diferenças binárias e um instalador de patch. Nenhuma ISO, ROM ou cópia dos arquivos completos do jogo é fornecida.

É necessário possuir uma cópia original e legalmente adquirida do jogo. Este projeto não oferece suporte para obtenção de jogos, imagens de disco ou meios de contornar proteções. Não distribua a ISO resultante nem arquivos modificados do jogo.

Projeto não oficial e sem vínculo com a Konami. Todos os nomes, marcas e direitos relacionados ao jogo pertencem aos seus respectivos proprietários.
